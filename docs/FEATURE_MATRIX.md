# Engineering RC feature matrix

| Workflow | Implementation and validation boundary |
|---|---|
| Camera discovery and capabilities | USB is preferred through bundled ADB and local forwards for control, preview and file transfer. LAN uses UDP discovery, last working address and optional manual pairing. The dashboard reports authorization and recovery states. Same-handset fallback reuses the capture ID. Camera2 reports camera and physical IDs, sensor size, capture formats, exposure/ISO/focus limits, zoom, AWB, stabilization and supported video tuples. Rear-camera ranking uses estimated field of view, stabilization and sensor size. The camera report includes logical and physical IDs, optical and stream metadata and the active physical camera where reported. The Sony IMX921 identity and real stream combinations require device confirmation. |
| Android operation | Live Camera2 preview, local exposure/focus/crop and white-balance controls, capability-adjusted capture presets, JPEG/RAW/DNG capture, native JPEG burst and video. Screen-on flag, wake lock, exit confirmation, local luma histogram, preview frame count, battery temperature and storage telemetry. Session planning, EAA and advanced analysis run on the PC. |
| Stills and Moon/Solar | Full native JPEG and DNG streams are independent of preview magnification. The maximum sensor mode is offered for single JPEG exposures only when Camera2 advertises it. Moon and Sun presets use the lower ISO bound, and Solar displays the required front-aperture filter warning. Burst, histogram and clipping remain available. |
| Zoom and ROI | Android pinch, live slider and double-tap reset synchronize ratio with the PC. Display magnification changes only rendering. Standard video has a separate centered sensor crop using Camera2 zoom ratio where available and active-array crop otherwise. Select a smaller supported stream for higher FPS. |
| Planetary video | Camera2 standard or constrained high-speed recording to H.264 MP4. Stop by time or Camera2 frame-start threshold. The dashboard shows Camera2 starts and loss events, the finalized MP4 sample count, and cadence gaps estimated from adjacent presentation timestamps. MediaCodec output timestamps are matched to Camera2 sensor timestamps inside the recording interval to count missing encoder outputs when the clocks align. The dashboard reports when alignment is unavailable. Standard video uses supported shutter/ISO and sensor crop. Constrained high-speed mode may override manual focus, exposure and crop, and uses local phone preview. Telescope stabilization preset disables OIS and EIS when supported. |
| Planetary review | Optional worker scores up to 240 uniformly sampled decoded video frames by central Laplacian energy and saves up to five ranked full-resolution PNGs. The dashboard and session journal report the sample count and scores. |
| Deep sky | Light, dark, flat and bias frame types, the reported maximum manual exposure and selectable fixed measured white balance, interval sequencing, and manual-light integration estimate. The Sequence Manager resumes from the last recorded exposure in the same session after a restart, restores settings, and rebuilds a live stack from received lights. Sequence requests keep a stable capture ID and Android persists a completion receipt to replay saved files after either app restarts. If the phone stops before finalizing the receipt, recovery retries that exposure with the original ID. |
| Calibrated live stack | JPEG or classic uncompressed 16-bit Bayer DNG preview. Build mean bias, dark and normalized flat masters from selected capture sessions, apply them to incoming preview pixels, register with bounded translation and small rotation, reject weak matches, update accepted/rejected counts and histogram, and export PNG. DNG masters and lights use a bounded debayered display preview. Full-resolution linear RAW output is handled separately through optional Siril. Vivo DNG layout compatibility requires a real capture. |
| Focus and histogram | Background-subtracted stellar HFR in a selectable 96-pixel focus area and Gaussian-equivalent FWHM with faint, clipped and non-stellar rejection. Focus history, centered magnification, clipping warning overlay, stack/live histogram, and relative lunar/planetary contrast. Pixel overlays run in a worker. |
| Capture processing | HAL-advertised noise reduction, edge, hot-pixel, tonemap and aberration controls. An optional measured color correction holds compatible Camera2 white-balance gains and matrix. RAW remains sensor DNG. Effective ISO, shutter, focus and stabilization come from capture results. |
| Session manager | Lists journals under Pictures / TOD Astro Photography / date / target / session. Shows verified progress and received files and supports resuming interrupted sequences. Journals include capture settings, time, telemetry, checksums and reconnect events. |
| Siril | Optional CLI staging and generated homogeneous conversion, calibration/master creation, debayering, registration and stacking script. The dashboard reports progress and checks the expected output. Validated with Siril CLI on synthetic JPEG light, bias, dark and flat sequences. Vivo RAW and Windows Siril launcher validation remain open. |
| Interoperability | Camera transport, journaling, and image processing remain separate from the web dashboard. ASCOM Alpaca, mounts, guiding, and plate solving are future integrations from the original requirements. |
