# TOD Astro Suite 1.0 Engineering RC

The Android artifact is an installable debug-signed APK. The Windows artifact is an unsigned standalone x64 executable that uses the Windows browser for its dashboard.

Physical Vivo T3 Ultra qualification is pending. It must confirm the main lens ID, JPEG/RAW stream combinations, high-speed modes, thermal behavior and recovery during sustained capture. See the [feature matrix](FEATURE_MATRIX.md) for remaining implementation work.
